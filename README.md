💱 Conversor de Moedas

Um projeto desenvolvido com **HTML, CSS e JavaScript** que permite converter valores entre diferentes moedas de forma simples, rápida e intuitiva.

<h2 align="center">🚀 Funcionalidades</h2> 

- 💵 Conversão entre:
  - Real (BRL)
  - Dólar (USD)
  - Euro (EUR)
  - Libra Esterlina (GBP)
  - Iene Japonês (JPY)
- 🔄 Seleção dinâmica da moeda de origem e destino.
- 💰 Formatação automática dos valores.
- 🌍 Exibição das bandeiras de cada moeda.
- 📱 Interface responsiva e moderna.
